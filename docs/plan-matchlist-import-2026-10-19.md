# Σχέδιο: Νέος τύπος εισαγωγής «Λίστα αγώνων» (μόνο ELO και στατιστικά)

**Ημερομηνία:** 2026-10-19
**Κατηγορία κινδύνου:** κανονική → branch + preview, merge μόνο μετά από έγκριση
(αγγίζει εισαγωγές, αντιστοίχιση παικτών και Πανελλήνια ELO)
**Αρχεία:** `lib/imports.js`, App.jsx (εισαγωγή, αντιστοίχιση, ELO, καρτέλα παίκτη,
Head-to-Head), `lib/eloRanking.js` αν εκεί γίνεται η συλλογή αγώνων από εισαγωγές
**Πρώτο αρχείο:** `saka_2026_matchlist.json` (ΣΑΚΑ 2026: Πρωτάθλημα 8th BG League και
Κύπελλο 7th BG Race, 214 αγώνες / 26 παίκτες)

## Αφορμή

Σύλλογοι που δεν τρέχουν τα τουρνουά τους στην εφαρμογή (π.χ. ΣΑΚΑ, με σύνθετο σύστημα
πρωταθλήματος σε φάσεις και Κύπελλο best of 3) μας στέλνουν αποτελέσματα. Θέλουμε να
φορτώνουμε **μόνο τους αγώνες**, για να εμπλουτίζεται η Πανελλήνια Κατάταξη ELO και τα
στατιστικά των παικτών, **χωρίς** να απαιτείται «τέλεια» διοργάνωση (γύροι, κατάταξη,
νικητής) και **χωρίς** καμία βαθμολογία.

Η σημερινή εισαγωγή (`bgfed-import/1`) δεν ταιριάζει: ένα τουρνουά έχει μία ημερομηνία,
ενώ εδώ οι αγώνες απλώνονται σε έναν χρόνο και για το ELO μετράει η χρονολογική σειρά.

## 1. Μορφή `bgfed-matchlist/1`

```json
{
  "format": "bgfed-matchlist/1",
  "name": "ΣΑΚΑ 2026 — Πρωτάθλημα ... και Κύπελλο ...",
  "sourceId": "saka-2026-league-and-race",
  "organiser": "ΣΑΚΑ",
  "sourceName": "...",
  "dateFrom": "2025-10-24", "dateTo": "2026-10-12",
  "players": ["ΔΑΜΗΣ", "..."],
  "matches": [
    { "id": "L1-1", "date": "2025-10-24", "time": "18:30",
      "p1": "ΠΑΠΑΓΡΗΓΟΡΑΚΗΣ", "p2": "ΧΑΤΖΗΜΙΧΑΛΗΣ", "winner": "ΠΑΠΑΓΡΗΓΟΡΑΚΗΣ",
      "score1": 11, "score2": 6, "matchLength": 11, "method": "normal",
      "label": "Πρωτάθλημα 8th BG League – Προκριματική φάση",
      "note": "...", "dateAssumed": false }
  ],
  "matching": { "format": "bgfed-matching/1", "rows": [ ... ] }
}
```

- `method`: `"normal"` (μετράει) ή `"walkover"` (δόθηκε νίκη χωρίς αγώνα, π.χ. no-show·
  `date` μπορεί να είναι `null`).
- `score1/score2`, `time`, `label`, `note`, `dateAssumed`: προαιρετικά.
- Κάθε παιχνίδι ενός best of 3 είναι **χωριστός αγώνας** (ήδη έτσι στο αρχείο).
- `sourceId`: σταθερό αναγνωριστικό· νέα εισαγωγή με ίδιο `sourceId` **αντικαθιστά** την
  παλιά (όπως το `sourceUrl` στις άλλες εισαγωγές).

## 2. Έλεγχος (`validateMatchlist` στο `lib/imports.js`)

- Σωστό `format`· κάθε `p1`, `p2`, `winner` υπάρχει στο `players`· `p1 ≠ p2`·
  `winner ∈ {p1, p2}`· `method ∈ {normal, walkover}`·
  `normal` ⇒ έγκυρη `date` (YYYY-MM-DD)· μοναδικά `id`.
- Περίληψη: παίκτες, αγώνες που μετράνε, αγώνες χωρίς αγώνα, πρώτη/τελευταία ημερομηνία,
  πλήθος με `dateAssumed`.
- Το `validateImport` / bundle δεν αλλάζουν.

## 3. Εισαγωγή (υπάρχουσα οθόνη Εισαγωγών)

- Το `onImportFile` δέχεται επιπλέον `bgfed-matchlist/1`.
- Προεπισκόπηση: όνομα, πηγή, περίοδος, παίκτες, αγώνες (μετράνε / χωρίς αγώνα),
  προβλήματα ελέγχου, «θα αντικαταστήσει» αν υπάρχει ίδιο `sourceId`, και λίστα των
  αγώνων με σημείωση (`note`) για έλεγχο.
- Επιλογή **Διοργάνωσης** (υποχρεωτική)· **Σεζόν δεν απαιτείται** για λίστα αγώνων
  (δεν έχει βαθμολογία). Το κουμπί «Εισαγωγή» ενεργό χωρίς σεζόν.
- Αποθήκευση όπως οι άλλες εισαγωγές (έγγραφο + εγγραφή στη λίστα εισαγωγών) με
  `kind: "matchlist"`, `competitionId`, `dateFrom/dateTo`.
- Αν υπάρχει `matching`: μετά την εισαγωγή ανοίγει η αντιστοίχιση με τις αποφάσεις
  φορτωμένες (ίδια ροή με το πακέτο). Η αντιστοίχιση (`buildMatchPlan`, `personMap`)
  πρέπει να περιλαμβάνει και τα έγγραφα `matchlist`.

## 4. Πού μετράνε οι αγώνες

| Περιοχή | Συμμετοχή |
|---|---|
| Πανελλήνια Κατάταξη ELO (και όποια κατάταξη περιέχει τη διοργάνωση) | **Ναι** — κάθε `normal` αγώνας στη δική του `date` (+`time`, μετά σειρά αρχείου), σε χρονολογική σειρά μαζί με όλους τους άλλους αγώνες. Recompute τους λαμβάνει υπόψη. |
| Win % στην ELO, καρτέλα παίκτη, Head-to-Head, Στατιστικά Παίκτη | **Ναι** (μόνο `normal`) |
| Ανάλυση «πώς προέκυψε αυτή η βαθμολογία» στην καρτέλα ELO | **Ναι**, με πηγή «όνομα λίστας · label» |
| Βαθμολογία σεζόν, λίστα τουρνουά, Κατακτήσεις/Τίτλοι, Νικητές ημέρας, Πρωτοπορία, Σερί, Στατιστικά Σεζόν | **Όχι** |
| Αγώνες `walkover` | Φαίνονται μόνο στο ιστορικό του παίκτη ως «χωρίς αγώνα»· **δεν** μετράνε πουθενά |

- Στην καρτέλα παίκτη (ιστορικό) οι αγώνες εμφανίζονται ως ενότητα «Αγώνες: {όνομα
  λίστας}» με ημερομηνία, αντίπαλο, αποτέλεσμα, `label`, χωρίς σύνδεσμο σε τουρνουά.
- Η λίστα αγώνων φαίνεται στη Διαχείριση → Εισαγωγές (με προβολή όλων των αγώνων της),
  και μετράει στον αριθμό «Τουρνουά» της διοργάνωσης ως «από τα οποία N εισαγωγές»
  (1 λίστα = 1).

## 5. Διοργάνωση (από τον χρήστη, χωρίς κώδικα)

Ο χρήστης φτιάχνει στη Διαχείριση τη διοργάνωση «Αγώνες ΣΑΚΑ» του συλλόγου ΣΑΚΑ,
χωρίς βαθμολογία, και την προσθέτει στις διοργανώσεις της Πανελλήνιας Κατάταξης ELO.
Αν κάτι από αυτά δεν γίνεται σήμερα από την οθόνη, επισήμανέ το.
