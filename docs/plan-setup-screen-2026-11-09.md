# Build 2026-11-09.04 — Νέο τουρνουά (δύο στήλες, επιβεβαίωση, ζωντανή ενημέρωση) + σταθεροί τίτλοι στον υπολογιστή

**Επίπεδο 2** · branch `claude/kind-tesla-vchqn9` → PR → έλεγχος στο preview από τον Γιάννη → merge **μόνο** με εντολή του.

## Αλλαγές
1. **Οθόνη «Νέο τουρνουά»** (region `Οθόνη: Νέο τουρνουά`): δύο στήλες — Ρυθμίσεις (αγωνιστική, γραμμή
   «ημερομηνία · σεζόν · αλλαγή» που ανοίγει τα πεδία, όνομα, γύροι, μήκος, διοργάνωση + σύλλογος, «Επίσημη αγωνιστική»,
   **«Ζωντανή ενημέρωση»**) | Παίκτες (μετρητής, πεδίο + Side bet + «Προσθήκη», «▸ Επικόλληση λίστας από Excel»
   πτυσσόμενο, λίστα **νεότερος πρώτος** με επισήμανση, ετικέτα «Στο μητρώο»/«Νέος παίκτης», ×, «Έναρξη τουρνουά»).
   Όλα στα Ελληνικά. Ίδιες συναρτήσεις: `addPlayer`, `addPlayersBulk`, `removePlayer`, `toggleDefaultSideBetForPlayer`,
   `applyCalendarEntry`, `renderSeasonSelect`, `startTournament`.
2. **«Ζωντανή ενημέρωση» ενεργή από προεπιλογή** σε νέο τουρνουά (`setLiveStandingsEnabled(true)` στην προετοιμασία
   νέου τουρνουά) και ρυθμίζεται από τις ρυθμίσεις· αποθηκεύεται με το τουρνουά όπως πριν (`liveStandingsEnabled` στο
   snapshot). Ο διακόπτης στην οθόνη ζευγαρωμάτων μένει. Τουρνουά που ήδη υπάρχουν: αμετάβλητα (φορτώνουν τη δική τους τιμή).
3. **Επιβεβαίωση έναρξης**: «Έναρξη τουρνουά» ανοίγει διάλογο (όνομα, παίκτες, γύροι/μήκος, ημερομηνία/σεζόν, side bet,
   σε τι μετράει, ζωντανή ενημέρωση, bye αν μονός αριθμός) → «Ναι, κλήρωση 1ου γύρου» καλεί το `startTournament()` όπως πριν.
4. **Σταθεροί τίτλοι πινάκων** (`styles/views.js`): > 1100px κυλάει η σελίδα και το `thead` κολλάει στην κορυφή
   (το `.table-scroll` χωρίς δική του κύλιση)· ≤ 1100px όπως στο `.03` (κύλιση μέσα στο πλαίσιο).

**Δεν αλλάζουν:** κλήρωση, ζευγαρώσεις, αντιστοίχιση ονομάτων, αποθήκευση παικτών, κανόνες Firestore.
